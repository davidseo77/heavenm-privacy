Privacy Policy

Application: HeavenM Global Listing Automation

Last updated: October 3, 2026

HeavenM Global Listing Automation is an internal commerce automation application operated by HeavenM. It is intended for authorized eBay API access, product catalog research, product data validation, and internal commerce integration development. It is not offered as a public consumer application.

1. Information We Access

When an authorized eBay account grants permission, HeavenM Global Listing Automation may access information made available through eBay APIs within the OAuth permissions granted by the account holder.

Depending on the applicable eBay API and authorized scope, this information may include:

  • eBay account authorization information;
  • OAuth authorization credentials and related authorization metadata;
  • product identifiers and eBay catalog information;
  • product titles, attributes, images, and other product metadata;
  • inventory-related information when required for an authorized API workflow;
  • technical API response data required for validation and integration testing.

HeavenM does not request, collect, or store an eBay user's password.

2. Purpose of Use

Information obtained through eBay APIs is used only for HeavenM's internal API integration, product identification, product catalog research, product data validation, product image validation, and related development and testing activities.

The application may request the eBay sell.inventory OAuth permission when required by the applicable eBay API for authorized catalog, product-data, or validation access.

HeavenM's current integration does not use eBay write APIs. OAuth permissions are used only to the extent necessary for authorized read, research, validation, development, and testing workflows.

3. Data Sharing

HeavenM does not sell eBay account information or eBay-derived personal information to advertisers or unrelated third parties.

Information may be processed by infrastructure or service providers only when reasonably necessary to operate, secure, maintain, or support the application.

4. Data Storage and Security

HeavenM applies reasonable technical and organizational safeguards to protect authentication credentials and information obtained through eBay APIs.

Access tokens, refresh tokens, client secrets, and other authentication credentials, when used or stored, are treated as confidential information and are not intentionally exposed in public repositories, public web pages, or publicly accessible logs.

5. Data Retention

Information obtained through eBay APIs is retained only for as long as reasonably necessary for authorized internal business purposes, API integration, validation, operational continuity, security, troubleshooting, or applicable legal obligations.

Data that is no longer reasonably necessary for these purposes may be deleted or anonymized where appropriate.

6. eBay Authorization and Revocation

Access to protected eBay account information occurs only after the applicable eBay account holder grants authorization through eBay's OAuth consent process.

The account holder may revoke application authorization through applicable eBay account or authorization settings.

After authorization is revoked, HeavenM will no longer use the revoked authorization credentials to access protected eBay account data.

7. eBay Catalog and Product Data

HeavenM may use authorized eBay API access to research and validate eBay catalog and product information, including product identifiers, attributes, catalog metadata, and catalog-associated image metadata when available.

eBay catalog data and third-party seller listing data are treated as separate data sources. HeavenM does not represent third-party seller content as HeavenM-owned content.

8. Changes to This Policy

HeavenM may update this Privacy Policy when the application's functions, data practices, legal requirements, or eBay API integration change.

The current version and revision date will be published on this page.

9. Contact

Questions regarding this Privacy Policy or HeavenM Global Listing Automation may be directed to HeavenM, the operator of this application.

Additional public contact information may be published here as HeavenM's public web services are established.
